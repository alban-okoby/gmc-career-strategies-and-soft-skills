# LinkedIn Profile Optimization & SSI Tracking

**LinkedIn Profile:** [View my LinkedIn profile](https://www.linkedin.com/in/alban-okoby-software-developer/)

## Repository Description
This repository documents the optimisation of my LinkedIn profile and the subsequent measurement of its impact using LinkedIn’s Social Selling Index (SSI).  
It includes a comparison of SSI scores before and one week after the changes, along with a brief analysis of the results and planned next steps.  
The goal was to apply best practices for professional branding, content engagement, and network growth.  
The final deliverables are the profile link and the SSI comparison table
